# 앞자리 PC 설치·실행 TXT 설계

## 목적

앞자리 PC에서 명함 자동발주 프로그램을 설치하고 계속 실행하기 위해 담당자가 실제로 수행해야 하는 작업만 한 개의 TXT 파일로 제공한다.

## 결과물

- 파일명: `앞자리PC_설치_실행.txt`
- 위치: 프로젝트 루트
- 고정 프로젝트 경로: `C:\Users\Felix\2026.06.24\홍은기\4. business_card_order_mailer`
- 형식: Windows 메모장에서 바로 읽을 수 있는 UTF-8 일반 텍스트

## 포함 범위

1. Python 의존성 설치 명령
2. 기존 운영 파일을 값 변경 없이 복사해야 한다는 체크 항목
3. 테스트와 1회 동기화 명령
4. 포털 실행과 접속 주소
5. Windows 로그인 시 자동실행 등록 명령
6. 자동실행 상태 확인·중지·재시작 명령
7. 기존 PC와 새 PC를 동시에 실행하지 않는다는 필수 주의사항

## 제외 범위

- 환경변수 각 항목의 의미
- 메일 주소, 계정, 비밀번호 등 실제 운영값
- 프로그램 구조나 기술 설명
- 상세 장애 대응과 업데이트 절차
- Git 설치와 저장소 복제 절차: 지정된 프로젝트 폴더가 이미 존재한다는 전제로 한다.

## 운영 전제

- 현재 프로젝트 폴더 전체를 앞자리 PC의 동일 경로로 복사한다.
- `.env`, `inbox` 설정, `output` 상태 파일은 값을 수정하지 않고 함께 이전한다.
- 메일 연동 모듈 `archive_mailer_api.py`가 코드가 요구하는 기존 상대 경로에 존재해야 한다.
- 최초 실행과 테스트는 직접 승인 상태에서 수행한다.
- 새 PC 자동실행을 시작하기 전에 기존 PC의 실행 프로세스를 종료한다.

## 구성

TXT는 다음 순서의 짧은 체크리스트로 작성한다.

1. 폴더 복사 확인
2. CMD에서 의존성 설치
3. 테스트와 1회 동기화
4. 수동 실행
5. 자동실행 등록
6. 상태 확인·중지·재시작

각 명령은 그대로 복사해 CMD에 붙여넣을 수 있어야 한다. 설명은 명령 실행에 필요한 한 줄을 넘기지 않는다.

## 검증 기준

- 고정 경로가 모든 명령에 일관되게 사용된다.
- 실제 비밀번호, 토큰, 메일 주소가 포함되지 않는다.
- `run_business_card_mailer.bat` 실행 명령이 포함된다.
- 포털이 자체적으로 주기 동기화하므로 별도 `monitor` 동시 실행을 안내하지 않는다.
- 자동실행 작업의 생성, 조회, 종료, 재실행 명령이 모두 포함된다.
- 미완성 문구나 임시 자리표시자가 없다.
