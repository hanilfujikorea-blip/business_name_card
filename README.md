# 명함발주 독립 개발 프로젝트

기존 사내 포털에서 **명함발주 기능만** 분리한 협업용 프로젝트입니다.

포함된 기능:

- 직원 정보 입력 및 한글·영문 명함 시안 미리보기
- 200매·400매 수량 선택
- JPG 시안 생성 및 발주 신청
- 본인 신청 이력, 승인·반려·취소 상태 확인
- 관리자 신청 검색·필터·승인·반려·재발송
- 자동·반자동 발송 설정 화면

다른 포털 메뉴, 직원 DB, 실제 로그인, 실제 SMTP 비밀번호는 포함하지 않습니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:3100`으로 접속합니다.

상단의 `직원 신청`과 `관리자 대시보드` 버튼으로 두 화면을 전환할 수 있습니다. 개발용 데이터는 브라우저가 아니라 로컬 서버의 `data/dev-db.json`에 저장됩니다.

## 검증

```bash
npm test
npm run build
npm start
```

`npm start`는 빌드된 화면을 `http://127.0.0.1:3101`에서 실행합니다.

## 개발용 데이터 주의사항

- `data/dev-db.json`: 개발 중 생성된 신청 이력
- `uploads/business-card-orders/`: 개발 중 생성된 JPG 시안
- `.env`: 개인 환경설정 및 비밀정보

위 파일은 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

개발용 서버는 기본적으로 실제 메일을 발송하지 않습니다. SMTP 설정을 GitHub에 올리지 마세요.

## 기존 포털로 합치기

병합 대상과 제외 대상을 [MERGE_GUIDE.md](MERGE_GUIDE.md)에 정리했습니다. 팀원이 수정한 기능 파일만 기존 포털에 반영하고, 독립 실행용 `App.tsx`, `server.cjs`, `data`는 합치지 않습니다.
