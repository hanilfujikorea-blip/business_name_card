K Group 명함 자동발주 - 앞자리 PC 설치 및 실행

[중요]
1. 앞자리 PC에서 실행하기 전에 기존 PC의 명함 자동발주 프로그램을 먼저 종료한다.
2. 두 PC에서 동시에 실행하면 중복 발송될 수 있으므로 절대 동시에 실행하지 않는다.
3. 아래 프로젝트 폴더 전체를 앞자리 PC의 동일한 위치로 복사한다.
   C:\Users\Felix\2026.06.24\홍은기\4. business_card_order_mailer
4. 기존 .env, inbox 설정, output 상태 파일은 값을 바꾸지 않고 그대로 복사한다.
5. 메일 연동 모듈도 다음 위치에 있어야 한다.
   C:\Users\Felix\2026.06.24\홍은기\3. SOA_fup_sales\archive_mailer_api.py

[1. CMD 열기]
Windows 검색창에 cmd를 입력하고 명령 프롬프트를 연다.

[2. Python 설치 확인]
아래 명령을 입력한다.

where py

py 경로가 나오면 다음 단계로 이동한다.
py를 찾을 수 없다고 나오면 아래 명령으로 설치한다.

winget install -e --id Python.Python.3.13

설치가 끝나면 CMD를 닫았다가 다시 연다.

[3. 필요한 프로그램 설치]
아래 명령을 한 줄씩 입력한다.

cd /d "C:\Users\Felix\2026.06.24\홍은기\4. business_card_order_mailer"
py -m pip install --upgrade pip
py -m pip install -r requirements.txt

[4. 프로그램 테스트]
아래 명령을 입력한다. 테스트에서는 실제 메일이 발송되지 않는다.

py -B -m unittest discover -s tests -v

마지막에 OK가 표시되는지 확인한다.

[5. 최초 1회 동기화]
운영포털이 직접 승인 상태인지 먼저 확인한 뒤 아래 명령을 입력한다.

py -B business_card_mailer.py sync

메일 확인 건수, 새 신청서 건수, 발송 가능 건수가 표시되는지 확인한다.

[6. 운영포털 실행]
아래 명령을 입력한다.

run_business_card_mailer.bat

이 CMD 창은 닫지 않는다. 창을 닫으면 프로그램이 종료된다.
다른 CMD 창을 열고 아래 명령으로 운영포털을 연다.

start "" http://127.0.0.1:8765/

[7. 자동실행 등록]
수동 실행과 동기화가 정상인 것을 확인한 뒤, 실행 중인 포털은 Ctrl+C로 종료한다.
CMD에서 아래 명령을 한 줄로 입력한다.

schtasks /Create /TN "KGroupBusinessCardPortal" /SC ONLOGON /DELAY 0000:30 /TR "'C:\Users\Felix\2026.06.24\홍은기\4. business_card_order_mailer\run_business_card_mailer.bat'" /RL LIMITED /F

등록한 작업을 즉시 실행한다.

schtasks /Run /TN "KGroupBusinessCardPortal"

[8. 자동실행 상태 확인]
아래 두 명령을 입력한다.

schtasks /Query /TN "KGroupBusinessCardPortal" /V /FO LIST
netstat -ano | findstr :8765

포털도 확인한다.

start "" http://127.0.0.1:8765/

[9. 자동실행 중지 및 재실행]
중지:

schtasks /End /TN "KGroupBusinessCardPortal"

다시 실행:

schtasks /Run /TN "KGroupBusinessCardPortal"

[마지막 확인]
1. 운영포털에서 기존 수신, 참조, 메일 문구가 그대로인지 확인한다.
2. 직접 승인 상태에서 동기화 결과와 발송 대상을 확인한다.
3. 이상이 없을 때 운영포털에서 자동 발송으로 전환한다.
4. 이후 기존 PC에서는 이 프로그램을 다시 실행하지 않는다.

[평소 직접 실행 명령]
cd /d "C:\Users\Felix\2026.06.24\홍은기\4. business_card_order_mailer"
